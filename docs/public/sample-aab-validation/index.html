判定方法与证明边界

每张证据卡按 Baseline 最终状态 → Kaleido 转换计划/映射 → 插件 AAB 最终状态 展示。 证据来自最终 Manifest、资源表、编译 XML、全部 DEX、ZIP 条目、raw/composed mapping、签名回执、 固定设备 APK Set 和 Dexcount；AAB 大小只作为量化指标，不单独决定插件是否有效。

本报告属于静态产物与可控构建证据。未安装或启动 APK，因此不声称设备运行、全部运行时路径、所有设备、 Google Play 审核或商店接受性已经验证。

总判定与限制

  • baseline-without-plugin.aab：有效对照，未运行 Kaleido。 类名、XML、资源、待删除条目和单 DEX 规模符合未应用插件的预期。
  • plugin-enabled.aab：Kaleido 有效。 四项核心能力和各功能点均有具体 before/after 数据，并由最终 AAB 或其固定设备 APK Set 反向确认。
  • 尚未验证：设备运行行为。 启动、资源加载、组件实例化和交互路径应由真机人工测试补充。

本次验证直接使用 AAB 的 ZIP、protobuf、DEX、mapping 和 Kaleido Release Evidence Set，形成可重复的产物证据链。
