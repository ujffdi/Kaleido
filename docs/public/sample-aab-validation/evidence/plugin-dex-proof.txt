Kaleido Sample plugin DEX proof
================================

Scope
-----

This is a curated proof extracted from the complete plugin DEX dump. It records
only the class descriptors needed by the report. The complete compressed dump is
published as plugin-dexdump.txt.gz in the GitHub prerelease.

The compiled and intermediate Compose descriptors each have zero class
definitions in the final dump. composed-mapping.txt binds the compiled facade
directly to C4464c49ea3, while raw-kaleido-mapping.txt and the raw R8 mapping
record the two transformation steps.

Reproduction commands
---------------------

Extract DEX files from plugin-enabled.aab, produce one text dump per DEX with
the Android SDK dexdump tool, and concatenate those text files in DEX filename
order. Then run:

  shasum -a 256 classes.dex classes2.dex
  rg -F "Class descriptor  : 'Lcom/tongsr/kaleido/sample/MainActivity;'" plugin-dexdump.txt
  rg -F "Class descriptor  : 'Lcom/tongsr/kaleido/sample/k0fdd3c/C0fdd3c6f42;'" plugin-dexdump.txt
  rg "Class descriptor.*Lcom/tongsr/kaleido/sample/kaleido/generated/components/" plugin-dexdump.txt | wc -l
  rg -F "Class descriptor  : 'LC4464c49ea3;'" plugin-dexdump.txt

The zero counts above were computed with the same exact-descriptor pattern and
wc -l so that a non-match is recorded as zero instead of being omitted.
