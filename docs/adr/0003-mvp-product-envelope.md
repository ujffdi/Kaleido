# Bound the MVP to an automatic AGP 9 Release AAB pipeline

The Kaleido MVP will combine the complete Core Capability Set in one automatic Hardening Pipeline: AndroidJunkCode-equivalent code/resource generation, XmlClassGuard-equivalent class and Manifest/XML reference processing, AABResGuard-equivalent final-AAB resource obfuscation and optimization, and deterministic R8 dictionary/mapping handling. Each Consumer Project is one Kaleido-applied Android Application Project whose independently processed flavored Release variants produce Regular, base-only AABs with ordinary library dependencies on AGP 9; unrelated Application Projects may coexist in the Gradle build without cross-Project state access. The MVP defaults to the Safe Profile with an explicit Full Profile and fails the build for transformations that could invalidate behavior or artifacts while reporting safe degradations. Within AndroidJunkCode-equivalent generation, the first publicly releasable MVP ships the Compose Generator as a disabled-by-default, explicitly enabled sub-capability for already Compose-enabled Consumer Projects; it is not a fifth capability family and does not change the mandatory status of the four families.
