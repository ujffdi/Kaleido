# Use typed Protection Requirements and bounded Escape Hatches

Kaleido represents runtime preservation as additive Protection Requirements for reachability, class/member identity, descriptors, attributes, resource names, and packaged paths rather than one keep switch. It automatically protects only finite, closed reference targets and accepts bounded, reasoned Escape Hatches for declared dynamic couplings; unresolved conflicts and unsupported topology fail without a global bypass. This deliberately preserves dependency-owned resource identities and some dynamically referenced names, trading maximum obfuscation coverage for auditable Release integrity across both Profiles.
