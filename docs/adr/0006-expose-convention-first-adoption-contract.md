# Expose a convention-first Adoption Contract

Kaleido exposes `com.tongsr.kaleido`, one optional provider-backed `kaleido {}` Interface, and the normal Release bundle command; plugin-only adoption resolves versioned Safe defaults while Full-only behavior, Compose, Protection Requirements, and upload signing remain explicit declarations. Every eligible Release variant consumes an immutable Adoption Plan, so four capability implementations, AGP task/artifact mechanics, seed domain separation, signing timing, and diagnostic policy stay behind one deep module seam. This trades arbitrary per-engine and per-variant flexibility for a stable, discoverable Consumer Project Interface whose defaults and migration behavior Kaleido can test and version.
