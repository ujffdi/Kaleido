# Kaleido 0.1.0 release notes

Kaleido 0.1.0 introduces the first complete Safe and Full deterministic Android
release-hardening pipeline, including optional Runtime-only Compose generation,
typed protection requirements, class and resource transformations, mapping
composition, final-AAB signing, and atomic Release Evidence Sets.

Development and release validation used AGP 9.2.0, Gradle 9.4.1, JDK 17, Build
Tools 36.0.0, and compileSdk 36 on macOS arm64. Other environments remain
unverified. This release makes no store-approval, SLSA-level, or absolute
runtime-unreachability claim.
