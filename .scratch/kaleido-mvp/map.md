# Find the way to a decision-complete Kaleido MVP

## Destination

Produce an evidence-backed, decision-complete definition of the first publicly releasable Kaleido MVP and its long-term product boundaries, ready to collapse into an implementation specification with `/to-spec`.

## Notes

- Domain language lives in [`CONTEXT.md`](../../CONTEXT.md); system-wide trade-offs live in [`docs/adr/`](../../docs/adr/).
- Every decision session uses `/grilling` and `/domain-modeling`; external facts use `/research` against primary sources.
- Planning produces decisions and evidence, not plugin implementation.
- Standing product decisions made before this map are recorded in ADR-0001 through ADR-0003.
- ADR-0002 fixes a source-informed independent AndroidJunkCode implementation; optional owner clarification may strengthen provenance but is neither an architecture nor publication gate, and upstream source expression/templates remain excluded without compatible permission.
- Sana is the first Reference Consumer, never a source of product-specific defaults.

## Decisions so far

<!-- Closed decision tickets are indexed here by name. -->

- [Establish upstream rights and reuse constraints](issues/01-research-upstream-rights-and-reuse.md) — AabResGuard is clearly Apache-2.0, AndroidJunkCode has artifact-level Apache-2.0 evidence with source/output ambiguity, and XmlClassGuard has no discovered reuse license.
- [Establish supported AGP 9 artifact seams](issues/03-research-agp9-artifact-seams.md) — Public AGP 9 APIs cover generation, class/Manifest transforms, R8 inputs, and post-signing BUNDLE transforms, but expose no complete merged-resource seam before signing.
- [Establish the MVP compatibility baseline](issues/04-research-version-compatibility.md) — AGP 9.0.1–9.3.2 is only a candidate range; JDK 17 and each AGP line's documented Gradle pair are the defensible test baseline pending Artifact API evidence.
- [Characterize AndroidJunkCode integration gaps](issues/11-prove-android-junk-adapter-guarantees.md) — The fixed dependency integrates with AGP 9 and preserves Consumer source, but fails reproducibility, Build Cache reuse, and callback input correctness; private adapter configuration cannot repair it.
- [Choose the upstream integration strategy](issues/02-choose-upstream-integration-strategy.md) — AndroidJunkCode and XmlClassGuard behavior are independently implemented inside Kaleido, while selected AABResGuard algorithms may be reused under Apache-2.0 with provenance and Kaleido-owned AGP integration.
- [Choose resource transformation and signing ownership](issues/14-choose-resource-transformation-and-signing-ownership.md) — AABResGuard-equivalent final-AAB processing is mandatory; Kaleido owns post-bundle transformation, re-signing, verification, and the single published final AAB without relying on AGP internals.
- [Define the capability contract for each engine](issues/05-define-engine-capability-contracts.md) — Both Profiles run all four core families; Safe stays runtime-quiet, Full explicitly exposes Activity and destructive resource controls, and deterministic reference-driven transformations fail closed.
- [Decide the Compose Generator delivery phase](issues/13-decide-compose-generator-delivery-phase.md) — The first public MVP ships the disabled-by-default Compose Generator within AndroidJunkCode-equivalent generation, and its detailed contract blocks release acceptance.
- [Define the automatic pipeline and artifact ownership](issues/07-define-automatic-pipeline-and-artifact-ownership.md) — One AGP artifact chain owns pre-R8 class/Manifest transforms, R8 mapping composition, deterministic final-Bundle rewrite, provider-backed re-signing and verification, and atomic publication of one Release Evidence Set.
- [Define supported project topology and rejection behavior](issues/09-define-supported-project-topology.md) — Each Kaleido-applied Application Project independently owns flavored Release/base-only AABs; unsupported module structures and confirmed dynamic-code mechanisms fail while ordinary dependencies remain analysis-only.
- [Resolve AndroidJunkCode license ambiguity without blocking publication](issues/15-obtain-android-junk-license-clarification.md) — Kaleido records the upstream Apache-2.0 metadata but independently authors the capability, copies no upstream source/templates without compatible permission, and does not require an owner response for the public MVP.
- [Define the keep and escape-hatch model](issues/16-define-keep-and-escape-hatch-model.md) — Additive typed Protection Requirements automatically close finite references, bounded Escape Hatches cover declared dynamic targets, dependency identities remain conservative, and unresolved integrity conflicts fail without a global bypass.
- [Define the adoption interface and Profiles](issues/06-define-adoption-interface-and-profiles.md) — Applying `com.tongsr.kaleido` alone resolves versioned Safe defaults, while one provider-backed product-intent DSL adds explicit Full controls, typed protection, deterministic inputs, and atomic per-variant signing without exposing engines or tasks.
- [Define the optional Compose Generator sub-capability contract](issues/12-define-compose-generator-contract.md) — Explicit opt-in generates deterministic Runtime-only Composable graphs, retains their inventoried members in final DEX, and fails on missing prerequisites or any statically identifiable Kaleido entry point.
- [Define the class, XML, and resource transformation algorithms](issues/17-define-transformation-algorithms.md) — Plan-first deep Modules apply reference-driven JVM/Kotlin class renaming and ID-preserving protobuf/ZIP resource rewriting with deterministic mappings, bounded file deduplication, and strict closure validation.
- [Define failure, reporting, and reproducibility contracts](issues/08-define-failure-reporting-and-reproducibility.md) — Stable fail-closed diagnostics and one canonical Artifact Report separate byte-reproducible unsigned evidence from non-cacheable signing/publication evidence bound into an atomic Release Evidence Set.
- [Define the upgrade, deprecation, and migration policy](issues/18-define-upgrade-and-migration-policy.md) — Exact tested compatibility matrices, SemVer-governed public contracts, finite Bridge Releases, immutable per-release evidence, and bounded report-reader support make upgrades explicit without promising indefinite compatibility.
- [Define release acceptance and publication](issues/10-define-release-acceptance-and-publication.md) — One immutable Candidate must pass mandatory A3/A4, device, artifact, reproducibility, performance, provenance, documentation, and Portal gates before its complete Kaleido Release Dossier permits public publication.
- [Establish the packaged plugin and Consumer Project seam](issues/19-package-plugin-consumer-seam.md) — A marker-resolved Java Consumer now applies the Java 17 plugin through temporary Maven, discovers AGP 9 Release identity, and finalizes the ordinary Bundle through one provider-wired artifact transform with stable application-order diagnostics.
- [Validate the supported adoption topology](issues/20-validate-supported-adoption-topology.md) — DSL, variant, and final-AAB gates now accept exact flavored minified base-only Release variants and ordinary dependencies while rejecting unsupported modules and confirmed dynamic-code/hotfix signals before any Kaleido output.
- [Implement the Safe Profile, DSL, and deterministic seed](issues/21-safe-profile-dsl-deterministic-seed.md) — The typed convention-first DSL now resolves one immutable per-variant Safe/Full Adoption Plan with exact Safe Defaults v1, lazy NFC/SHA-256 seed fingerprinting, domain-separated streams, bounded validation, and Configuration Cache reuse.
- [Generate Safe ordinary Junk Code and resources](issues/22-generate-safe-junk-code-resources.md) — Each eligible Release now deterministically generates bounded ordinary Java/resources, an inert Manifest fragment, keep rules, and a canonical inventory through public AGP Sources APIs; exact counts, collision failure, byte stability, variant isolation, R8, and real AAB packaging are verified.
- [Complete the first class and Manifest rewrite tracer](issues/23-class-manifest-rewrite-tracer.md) — A plan-first PROJECT class transform and semantic merged-Manifest transform now emit deterministic protobuf plan/receipt plus raw mapping, preserve dependency/protected identities, close final Manifest/DEX references, and cold-start the renamed Activity on the controlled AVD fixture.
- [Close Kotlin, XML, and Protection Requirement references](issues/24-kotlin-xml-protection-closure.md) — Strict Kotlin Metadata and full ASM remapping now close supported JVM families; generated semantic-XML overlays coordinate with the same class plan, while typed additive Protection/Escape Hatches, reflection/JNI inference, R8 rules, resource conflict checks, and negative closure gates are verified.
- [Integrate deterministic R8 dictionaries and composed mappings](issues/25-deterministic-r8-dictionary-mapping.md) — Each Release now feeds R8 canonical seed-derived member/class/package dictionaries and exact semantic-identity rules, preserves the original R8 9.2 mapping plus provenance metadata, and publishes a structurally composed original-to-final mapping verified by byte-stability and real Java/Kotlin Retrace tests.
- [Implement the Compose Junk Code Generator](issues/26-compose-junk-code-generator.md) — Explicit opt-in now produces a deterministic Runtime-only acyclic Compose graph, validates compiled closure and Consumer non-reachability, retains the exact obfuscatable inventory through R8, and proves the final mapped lowered functions in DEX evidence.
- [Complete the final-AAB resource rewrite tracer](issues/27-final-aab-resource-rewrite.md) — A plan-first final Bundle transform now preserves all resource IDs and code/native payload bytes while coordinating deterministic application-resource names, protobuf references, compiled XML, file paths, ZIP entries, unsigned canonical output, mapping/receipt evidence, and bundletool validation; dependency and protected identities remain unchanged.
- [Add resource protection, deduplication, and canonicalization](issues/28-resource-protection-dedup-canonicalization.md) — Typed and automatically inferred resource protections now carry hash evidence through the plan and receipt; compatible unprotected payloads deduplicate without merging IDs, incompatible/protected/shared-path cases remain intact with stable diagnostics, and independent builds produce byte-identical canonical unsigned AABs and mappings.
- [Implement Full Profile component generation](issues/29-full-profile-component-generation.md) — Explicit Full-only Activity generation now emits deterministic inert classes and non-exported declarations, closes them through class/Manifest rewriting and raw/composed mappings, rejects collisions before mutation, and preserves the Consumer launch path in a controlled device smoke.
- [Implement Full Profile destructive resource controls](issues/30-full-profile-destructive-resource-controls.md) — Explicit Full-only native/metadata deletion, confirmed-unused plain-string replacement, and fallback-safe language filtering are now plan-first, ownership/protection/reference gated, digest-bound, bundletool-valid, and byte-reproducible while Safe remains unchanged.
- [Select signing atomically and verify the final AAB](issues/31-signing-selection-aab-verification.md) — One complete execution-time credential source now signs the exact canonical unsigned digest, verifies coverage/certificate/Bundle/code-transparency integrity with redacted evidence, and retains the result as a staged candidate for atomic Release Evidence Set publication.
- [Publish an atomic Release Evidence Set](issues/32-atomic-release-evidence-set.md) — One final publication transform now validates and atomically exposes the signed standard AAB plus a canonical, independently rehashable Release Evidence Set containing all deterministic stage evidence, four mappings, Artifact Report 1.0, publication proof, and a path-independent set identity while preserving prior success on failure.
- [Pass cache, up-to-date, and byte-reproducibility gates](issues/33-cache-reproducibility-gates.md) — Eight deterministic stages now use versioned cache contracts while secrets, signing, validation, and publication always execute; independent fixtures prove Configuration Cache reuse, no-clean up-to-date reuse, same/relocated Consumer cache restoration, variant-isolated invalidation, and three-workspace byte reproducibility.
- [Implement version, schema, and migration contracts](issues/34-version-schema-migration-contract.md) — Public surfaces now obey explicit patch/minor/major rules and finite Bridge windows; URI-versioned Artifact Reports are validated by a bounded current/previous-major reader, and immutable historical evidence can only produce separately identified digest-bound derived views.

## Not yet specified

None. The map is decision-complete and ready to collapse into an implementation specification with `/to-spec`.

## Out of scope

- Implementing Kaleido while this decision map is open.
- Promising review evasion, application unlinkability, or store approval.
- AGP 8.x, APK hardening, Dynamic Feature, Instant App, multiple Application modules, pluginization, hot-fix frameworks, and runtime dynamic loading in the MVP.
- Accounts, cloud services, telemetry, paid features, or enterprise licensing in the MVP.
