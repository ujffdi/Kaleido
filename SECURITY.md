# Security policy

No public Kaleido version is supported until its immutable Release Dossier says
`PASS`. Report suspected vulnerabilities privately to the repository security
contact configured on the authoritative GitHub project. Include the affected
version, diagnostic, minimal sanitized reproduction, impact, and whether public
disclosure has occurred. Do not include credentials, signing material, private
private Consumer Project behavior, personal paths, or customer data.

The maintainers will classify product versus infrastructure failure, preserve
the public artifact, issue an advisory when necessary, and release a newly gated
patch. Security reports are not promises of store approval or absolute runtime
protection; the boundaries are in
[`docs/public/security-model.md`](docs/public/security-model.md).
