# Security policy

Report suspected vulnerabilities privately to the repository security contact
configured on the authoritative GitHub project. Include the affected version,
diagnostic, minimal sanitized reproduction, impact, and whether public disclosure
has occurred. Do not include credentials, signing material, private Consumer
Project behavior, personal paths, or customer data.

The maintainers will classify the failure, preserve the public artifact, issue
an advisory when necessary, and publish a patch. Security reports are not
promises of store approval or absolute runtime
protection; the boundaries are in
[`docs/public/security-model.md`](docs/public/security-model.md).
